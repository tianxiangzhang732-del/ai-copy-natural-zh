# 可选配置：中文短视频口播

仅在用户需要短视频口播时采用。以下是可选表达偏好，不替代主技能，也不自动套用到所有中文写作。

## 听得懂、讲得顺

- 根据已有事实，把关键变化放进观众熟悉的具体任务。假设场景明确说是假设，不虚构作者亲历。
- 用对话推进、具体动作、成本与利益关系、真实反差帮助理解；工作、学习和生活处境题可以增加有依据的铺垫与情绪。
- 每段增加理解，不反复回扣同一句好处；不强制每段先喊态度，不每隔几句安排悬念。
- 保留立场与表达力度。少用长定语、连续反问、整齐排比和报告式抽象名词。
- 固定开头、结尾、称呼、禁用词、字数与目标时长均以用户实际提供为准。没有提供时不自动添加账号口号。

## 江浙普通话偏好

仅当用户选择这项偏好时，按语义做词语适配，不重写整篇句子、不整体软化、不强加地方语气词：

| 原句 | 可选调整 |
| --- | --- |
| 还得我盯着 | 还要我盯着 |
| 总得给他一个理由吧 | 总要给他一个理由吧 |
| 这事得先弄清 | 这事要先弄清 |

只处理助动用法；“觉得、值得、得到”以及正常的“的、地、得”不机械替换。

## 与制作流程衔接

若用户已有候选稿、选稿和锁稿流程，按原流程执行。本技能只增加表达复核。锁定正文只审不改；明确授权修改时，同步更新用户要求的母稿、字幕、句子编号、素材锚点等受影响内容。

时长仅按用户指定语速或合理假设估算，说明口径并计入停顿。未提供真人录音时，不生成或声称校准了真实切点。
