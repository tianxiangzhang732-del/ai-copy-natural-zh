# ai-copy-natural-zh

**让中文文案讲得清楚、读得自然，保留事实和作者的声音。**

这是一份可独立使用的中文编辑技能。它帮助检查空话、报告腔、翻译腔、重复总结和僵硬节奏，适用于文章、短视频口播、标题、发布文案及日常文字。

只改有具体问题的地方。自然的句子可以保留，必要的术语、限定和正式表达也可以保留。

## 快速使用

核心规则都在 [SKILL.md](SKILL.md) 中，单独使用这一个文件即可。`references/` 是按需查阅的补充材料。

1. 在 GitHub 点击 **Code → Download ZIP**，解压后找到 `SKILL.md`；也可打开 [SKILL.md 原文](https://raw.githubusercontent.com/tianxiangzhang732-del/ai-copy-natural-zh/main/SKILL.md)。
2. 在支持附件的对话中上传该文件，或把文件内容复制到对话里。
3. 提供待处理文字，并说明用途、允许修改的范围和希望保留的风格。

可复制的提示词：

```text
请按我提供的 SKILL.md 处理下面的中文文案。

用途：[例如：短视频口播 / 文章 / 产品说明]
任务：[改稿 / 只审不改 / 基于材料独立创作]
允许修改的范围：[全文 / 指定段落]
风格要求：[未指定时，保留原文语气]
必须原样保留的内容：[引语、术语、固定首尾等；没有则填“无”]

先理解内容，再做必要的表达调整。保留事实、数字、归因、
否定、条件和判断强度，不编造经历、数据或来源。
已锁定的正文只审不改；只审稿时，列出具体问题，不交替换全文。
改稿时交一份完整成稿，必要说明放在正文之外。

待处理文字：
[在这里粘贴]
```

## 不同模型与工具

能接收文本指令的模型都可以读取这份规则。使用 ChatGPT、Claude、Gemini、豆包、DeepSeek、通义千问等工具时，可以按上述方式上传或粘贴；具体能否上传文件、保存指令或自动调用技能，取决于所用产品与版本。本项目没有承诺这些产品都支持原生技能安装，也不保证不同模型输出一致。

能读取本地文件的代理工具，可以先下载仓库：

```bash
git clone https://github.com/tianxiangzhang732-del/ai-copy-natural-zh.git
```

然后让工具读取仓库根目录的 `SKILL.md`，再提供任务。下载仓库本身不代表已安装或已加载。若宿主支持技能目录，请按该宿主的说明配置；不同工具的目录与加载方式可能不同。

`agents/openai.yaml` 是可选的宿主元数据。通用文本用法不依赖它，上游参考中的工具名称也不会为模型授予工具权限。

## 编辑边界

- **事实和含义优先。** 保留谁做什么、时间、范围、条件、归因和完成状态，不把“可能”写成“已经”。
- **遵守授权范围。** 锁定稿只审不改；局部修改不扩展到全文；引语、代码、路径、编号和数据字段受到保护。
- **保留作者声音。** 不统一改成碎片短句，不硬加口头禅，不虚构亲身经历，不强迫所有文本口语化。
- **表达复核不能代替事实核验或原创创作。** 基于参考材料创作时，仍需独立组织内容；仅换词不构成原创证明。
- **不判定作者身份。** 不输出“AI 含量”，不承诺通过检测器、平台审核或获得传播效果。
